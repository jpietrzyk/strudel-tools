# Plan: Fix Strudel Playback — CSP-Safe Evaluator

## Problem

`evaluate()` from `@strudel/web` internally uses the `Function()` constructor, which is **blocked by VS Code's webview Content Security Policy**. The error is silently swallowed by the repl's catch block, causing `evaluate()` to resolve to `undefined` with no audio output.

Logs confirm:
```
evaluate resolved. Result: undefined   ← Function() threw, catch swallowed it
[status] playing                       ← false positive, nothing is playing
```

## Solution: Custom Safe Evaluator

Replace `evaluate()` with our own evaluator that:
1. Runs the strudel **transpiler** (text→text, uses acorn, no `Function()`) on the user's code
2. **Parses** the transpiled code with acorn into an AST
3. **Walks** the AST against a sandboxed scope (`strudelScope` / `globalThis`) — only allows safe node types (literals, identifiers, calls, member expressions, binary/unary ops)
4. Feeds the resulting `Pattern` to `repl.setPattern(pattern, true)` directly

This approach:
- Supports **arbitrary strudel code** (not just mini-notation)
- Works within VS Code's CSP (no `Function()` / `eval()`)
- Uses acorn which is already bundled via `@strudel/transpiler`
- Uses `estree-walker` which is already a transpiler dependency

## Architecture

```
User code string
    │
    ▼
@strudel/transpiler (text→text transform: "bd sd" → m("bd sd"), labels, etc.)
    │
    ▼
acorn.parse() → AST
    │
    ▼
estree-walker (sync walk) → evaluate against strudelScope
    │
    ▼
Pattern object
    │
    ▼
repl.setPattern(pattern, true) → scheduler → webaudio → speakers
```

## Implementation Steps

### Step 1: Create `src/webview/safeEval.ts`

A CSP-safe evaluator module:

```typescript
import { parse } from 'acorn';
import { walk } from 'estree-walker';
import { strudelScope } from '@strudel/core';
import { transpiler } from '@strudel/transpiler';

export function safeEval(code: string): unknown {
  // 1. Run transpiler (text→text: mini-notation strings → m() calls, etc.)
  const transpiled = transpiler(code);
  const jsCode = transpiled.output;

  // 2. Parse to AST
  const ast = parse(jsCode, {
    ecmaVersion: 2022,
    allowAwaitOutsideFunction: true,
    sourceType: 'module',
  });

  // 3. Walk and evaluate against strudelScope
  function evalNode(node): unknown {
    switch (node.type) {
      case 'Program':
        // Evaluate last expression statement
        const lastStmt = node.body[node.body.length - 1];
        return evalNode(lastStmt);
      case 'ExpressionStatement':
        return evalNode(node.expression);
      case 'Literal':
        return node.value;
      case 'Identifier':
        const val = strudelScope[node.name] ?? globalThis[node.name];
        if (val === undefined) throw new Error(`Unknown identifier: ${node.name}`);
        return val;
      case 'CallExpression':
        const callee = evalNode(node.callee);
        const args = node.arguments.map(a => evalNode(a));
        return callee(...args);
      case 'MemberExpression':
        const obj = evalNode(node.object);
        const prop = node.computed ? evalNode(node.property) : node.property.name;
        return obj[prop];
      case 'BinaryExpression':
        const left = evalNode(node.left);
        const right = evalNode(node.right);
        // support arithmetic on patterns
        switch (node.operator) {
          case '+': return left + right;
          case '-': return left - right;
          case '*': return left * right;
          case '/': return left / right;
          default: throw new Error(`Unsupported operator: ${node.operator}`);
        }
      case 'UnaryExpression':
        const arg = evalNode(node.argument);
        switch (node.operator) {
          case '-': return -arg;
          case '!': return !arg;
          default: throw new Error(`Unsupported unary: ${node.operator}`);
        }
      case 'AwaitExpression':
        return evalNode(node.argument);
      case 'ArrayExpression':
        return node.elements.map(e => evalNode(e));
      case 'ObjectExpression':
        const obj = {};
        node.properties.forEach(p => {
          const key = p.computed ? evalNode(p.key) : p.key.name || p.key.value;
          obj[key] = evalNode(p.value);
        });
        return obj;
      case 'ChainExpression':
        return evalNode(node.expression);
      default:
        throw new Error(`Unsupported AST node: ${node.type}`);
    }
  }

  return evalNode(ast);
}
```

### Step 2: Update `src/webview/main.ts`

Replace `evaluate()` from `@strudel/web` with our safe evaluator + `repl.setPattern()`:

```typescript
import { initStrudel, hush, samples, initAudioOnFirstClick } from '@strudel/web';
import { webaudioRepl } from '@strudel/webaudio';
import { evalScope, Pattern } from '@strudel/core';
import { registerSynthSounds } from '@strudel/webaudio';
import { transpiler } from '@strudel/transpiler';
import { miniAllStrings } from '@strudel/mini';
import { safeEval } from './safeEval';

let repl;
let connected = false;

async function init() {
  initAudioOnFirstClick({ disableWorklets: true });
  miniAllStrings();

  // Create repl WITHOUT transpiler (we handle eval ourselves)
  repl = webaudioRepl();

  // Load modules onto globalThis
  await evalScope(
    evalScope,
    import('@strudel/core'),
    import('@strudel/mini'),
    import('@strudel/tonal'),
    import('@strudel/webaudio'),
  );
  await registerSynthSounds();
  await samples('github:tidalcycles/dirt-samples');
}

async function play(code: string) {
  if (!connected) await init();
  try {
    const pattern = safeEval(code);
    if (pattern instanceof Pattern) {
      await repl.setPattern(pattern, true);
    } else {
      throw new Error('Code did not return a Pattern');
    }
  } catch (e) {
    vscode.postMessage({ type: 'error', value: String(e) });
  }
}

function stop() {
  repl?.stop();
}
```

**Key changes:**
- Don't use `initStrudel()` — it creates a repl with the transpiler AND its `evaluate()` uses `Function()`. Instead, build our own initialization sequence.
- Create `webaudioRepl()` without passing a transpiler — we'll set patterns directly.
- Use `safeEval()` for code evaluation, then pass the resulting Pattern to `repl.setPattern()`.
- Keep `initAudioOnFirstClick({ disableWorklets: true })` for VS Code webview compatibility.

## Known Limitations

1. **No AudioWorklet sounds** — `disableWorklets: true` means sounds like `supersaw`, `pulse`, `bytebeat` won't work. Basic oscillators (`sawtooth`, `sine`, `triangle`, `square`) and samples work fine.
2. **AST evaluator limitations** — The safe evaluator supports function calls, member access, literals, binary/unary ops, arrays, objects. It does NOT support:
   - Variable assignments (`let x = ...`)
   - Function definitions (`const f = () => ...`)
   - Control flow (`if/else`, `for`, `while`)
   - Template literals
   These could be added later but cover 95% of typical strudel patterns.

### Key decisions made during implementation:
- **No separate `safeEval.ts` file** — evaluator is inline in `main.ts` since it's tightly coupled with the strudel imports and repl setup
